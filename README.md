# Pi Agent Template

This repository is a starter template for Pi Agent projects.

## Notes
- `agents/team.yml` defines the dispatcher roster and orchestrates the main workers. This keeps handoffs organized and helps the team stay coordinated.
- `pi-pi` is the expert on Pi Agent configuration and project setup. Launch it with `/pi-pi` when you need help with agents, skills, prompts, settings, or themes.
- Theme switching has a shortcut for changing the active theme: `Alt+1` for the table theme and `Alt+2` for the grid theme.
